Understanding PAN Structure

Position Characters Meaning
1–3AAA–ZZZ (letters)Alphabetic series — represents the issuing officer's area code (assigned by Income Tax dept)
4A–Z (letter)Entity type — identifies the taxpayer category (P=Person, C=Company, H=HUF, F=Firm, etc.)
5A–Z (letter)For individuals: first letter of surname. For non-individuals: first letter of entity name
6–90000–9999 (digits)Sequential number issued by Income Tax dept
10A–Z (letter)Alphabetic check digit
